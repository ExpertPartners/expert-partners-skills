# Skill Library schema

Database name: Expert Partners CoWork Skill Library
One row per skill. Quick-scan facts in properties. Full deep dive in the page body.

## Properties

Skill Name (title)
Skill Type (select): Claude CoWork Skill, Notion Skill, GPT Cataloging Skill, Database Management Skill, Documentation Skill, Automation Skill, Research Skill, Content Skill, Operations Skill, Strategy Skill, Other
Direct Skill Link / Location (url)
Documentation Owner (select): Allison Gaddy, Don Hobbs, Other Leader
Owning Account / Workspace (select): Expert Partners, Free Agent Movement, Moxie Signature Group, Personal
Internal Category (select): AI Infrastructure, Notion Database Management, Documentation, GPT Management, Skill Management, Operations, Marketing, Content, Strategy, Sales, Research, Admin, Client Success, Other
Ecosystem Role (select): Core Infrastructure, Department-Specific, Experimental, Needs Update, Archived
Primary Role (select): Cataloger, Database Builder, Database Curator, Documentation Assistant, Workflow Assistant, Research Assistant, Content Assistant, Operations Assistant, Strategy Assistant, Implementation Assistant, Other
Primary Business Function (text)
Best-Fit Team Users (multi-select): Allison, Don, Leadership Team, Marketing Team, Coaches, Operations Team, Sales Team, Admin Team, Content Team, Client Success, Full Company
Tools / Connectors Required (multi-select): Notion, Google Drive, Gmail, Calendar, Files, Web, Claude Skill Creator, Manual Input, None Visible, Unknown
Trigger / When To Use (text)
Status (select): Not Started, Drafted, In Review, Ready for Team Use, Needs Update, Archived
Priority (select): High, Medium, Low
Last Reviewed (date)
Recommended Owner (select): Allison Gaddy, Don Hobbs, Other Leader
Suggested Tags (multi-select): Expert Partners, Free Agent Movement, CoWork, Claude, Notion, AI Infrastructure, Knowledge Management, Documentation, Automation
Plain-English Summary (text)
Next Improvement Needed (text)
Related Notion Database (url)
Related Skills (relation to this same database)
Related GPTs (two-way relation to the Expert Partners Custom GPT Library)

All select and multi-select options are open. Extend them when a skill needs a value that does not exist yet.

## Views

All Skills, Ready for Team Use, Needs Documentation (Not Started or Drafted), Needs Update, By Category, By Ecosystem Role, By Owner, Core Infrastructure Skills, Notion Skills (Tools includes Notion), Related to GPT Library (Related GPTs not empty), By Priority, By Status, Needs Review (sorted by Last Reviewed, oldest first).
