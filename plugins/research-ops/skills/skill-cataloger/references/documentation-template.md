# Page body template (19 sections)

Use plain-text section headers. No dividers, no bold, no italics, no em dashes. Duplicate the live template page rather than retyping this when possible.

Section 1: Skill Identity Snapshot
Skill name, skill type, direct skill link / location, created by / documentation owner, owning account / workspace, internal category, ecosystem role, primary role, primary business function, best-fit team users, one-sentence positioning statement, one-sentence explanation of what this skill does.

Section 2: Configuration Snapshot
Skill files / artifacts, tools / connectors required, related Notion database, related GPTs, related skills, status, priority, last reviewed.

Section 3: Executive Summary
3 to 5 short paragraphs: what it is, why it exists, what business problem it solves, how it supports the Expert Partners and Free Agent Movement AI ecosystem.

Section 4: What This Skill Is Built To Do
Main business problem, workflow supported, work produced, transformation created, what it functions as.

Section 5: Who This Skill Is Best For
Internal users, skill level or context needed, when to choose it, when to use a different tool.

Section 6: Required Inputs
What the user must provide for the skill to work well.

Section 7: Typical Outputs
What the skill creates or updates.

Section 8: Workflow
Step 1 through Step 5.

Section 9: Best Use Cases
For each: use case name, what to use it for, input, output, example request.

Section 10: What This Skill Is Especially Good At
Strongest workflow, deliverables, operational value, documentation value, ecosystem value.

Section 11: What This Skill Should Not Be Used For
Out of scope, needs human review, needs manual verification, data it should not invent, when to switch tools.

Section 12: Tools, Connectors, and Dependencies
Required connectors, Notion access, files, databases, manual steps, known limitations.

Section 13: Related Skills, GPTs, and Databases
Overlaps, dependencies, complements, connected GPTs, databases it creates or manages.

Section 14: Prompting Guide
What to say to invoke it, what context to provide, weak vs strong requests, 10 reusable prompts.

Section 15: Quality Control Checklist
Name clear, owner listed, status listed, ecosystem role listed, inputs clear, outputs clear, related databases linked, related skills linked, plain-English summary included, next improvement included.

Section 16: Suggested Improvements
Missing fields, missing workflows, missing integrations, better routing logic, better structure, companion skills that should exist.

Section 17: Notion-Ready Skill Library Entry
The full copy-paste block of every field, for quick reference.

Section 18: Final Recommendation
How to use it in the company, who, when, what to connect it to, classification.

Section 19: Plain-English Summary
3 to 5 short paragraphs a team member can read fast to know what it does and when to use it.
