# Week Wrap acceptance cases

The skill sections and output contract are the implementation specification. Cases below map to those numbered sections. Store real inputs, outputs and comparisons privately in AG Personal Marketing, never in this repository.

Repository validation proves packaging and static instruction integrity, not successful business execution. A build-only assignment must not invoke the operational skill or edit live teaching assets. Record live cases as not run until the assignment includes a real run. Do not manufacture before evidence for a new skill.

## Exact acceptance rules

All exact rules must pass. There is one skill named week-wrap, displayed as Week Wrap. Both input routes produce the same three output types. There is no second deck. Existing output identities survive retry and revision. Every chapter slide has a full script in actual saved Canva notes. Both Docs and the private log live in the resolved AG Personal Marketing folder. The advantage brief renders as one page at the live standard's readable size. Run-of-show segment times sum to its stated duration.

Every substantive factual claim has evidence or an explicit hypothesis or unknown label. There are no source instructor or training-program names or attribution in any teaching output, including notes and metadata. There is no private personal information in teaching outputs or receipts. Status is complete only for three verified saved outputs and a saved log entry.

For AI-written quality, judge the teaching package against the actual source packet and the live brand canon. The tolerance permits different wording, not changed facts, omitted limits or unsupported claims. Allison must be able to teach cold from the notes, understand the origin in our terms and follow every exercise and transition. Evaluate those qualitative criteria with three independent judges when the live test is authorized. A criterion fails when two agree it is wrong against the source. Exact-rule failures do not need a qualitative vote.
