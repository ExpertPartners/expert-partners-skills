# YouTube Studio map

Verified against YouTube Help in September 2026. Re-check if the user reports a changed interface.

## Profile

YouTube Studio > Customization > Profile

Use for:
- Channel name
- Handle
- Description
- Profile links
- Contact information
- Profile picture / branding controls as surfaced in the current interface

YouTube currently supports up to 14 channel profile links. The first link receives prominent placement near the subscribe area, so put the primary CTA first.

Official Help:
- Manage your YouTube channel's profile: https://support.google.com/youtube/answer/2657964

## Channel branding

Use a banner that respects YouTube's current cropping guidance.

Current official guidance:
- Recommended banner: 2560 x 1440 px
- Minimum upload: 2048 x 1152 px, 16:9
- Safe area for text/logos at the minimum dimension: 1235 x 338 px
- File size: 6 MB or smaller

Official Help:
- Manage your channel branding: https://support.google.com/youtube/answer/10456525

## Channel keywords

YouTube Studio > Settings > Channel > Basic info > Keywords

Official Help:
- Manage channel settings: https://support.google.com/youtube/answer/2976814

## Playlists

YouTube Studio > Content > Playlists

Current Studio also supports creating a playlist from Create > New playlist.

Official Help:
- Manage playlists in YouTube Studio: https://support.google.com/youtube/answer/10232933

## Home tab

YouTube Studio > Customization > Home tab

Use for:
- Channel trailer
- Featured video
- Featured sections
- For You and other available channel sections

Official Help:
- Customize your YouTube channel layout: https://support.google.com/youtube/answer/3219384

## Upload defaults

YouTube Studio > Settings > Upload defaults

Current official behavior:
- Configure Basic info and Advanced settings
- Defaults can include privacy, category, title, tags, comments, language, and more
- Upload defaults apply to browser uploads on youtube.com/upload
- Mobile uploads and uploads from some video editors do not inherit these defaults

Official Help:
- Set default upload settings: https://support.google.com/youtube/answer/2660027
