# Curation output

Use this shape unless a shorter answer is clearly enough. Plain words, no tracking numbers in anything Allison reads.

## Verdict

Existing-repo verdict. The verdict repo-standards returned, USE EXISTING REPO or NEW REPO JUSTIFIED, or for an existing repo its ORGANIZE EXISTING REPO action recommendation. If repo-standards has not run, say so and do not invent one.

Durable job. One sentence.

Owner. The owner named by the repo's Archive Index row and current authority.

Why this home. Two to five sentences comparing the real candidates and explaining the boundary.

## Boundary

- Owns.
- Consumes by pointer.
- Does not own.
- External systems of record.

## Material routing

| Material | Class | Disposition | Home | Evidence |
| --- | --- | --- | --- | --- |
| path or item | class from the skill's triage table | keep, point, route, distill, preserve as history, needs review, or propose removal | repo path, Drive brain and folder, 1Password, or system of record | the source that shows the home |

Sensitive items appear by path and handling need only, never by content.

## Front door

Name only the files the repo's job justifies, one line each.

## Smallest next pass

The smallest reversible step that improves the repo without a broad restructure. A new repo goes back to repo-standards stage B. Any move into Drive names the relabel it needs.

## Stopped and waiting

- Items marked needs review, each with the source that would settle it.
- Failed reads or conflicts, each named.
- Decisions for Allison, one line each with a recommendation.
