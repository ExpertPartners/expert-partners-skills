# Session record template

Title: `Session Record [PROJECT] [YYYY-MM-DD]`. Written for a reader with zero memory of the chat, built from artifacts and repo state. Save it in its owning home and link it in the final report.

## Sections, in order

1. Mission. What this session worked on and why.
2. Decisions. Each one: the decision, the context, alternatives rejected, consequences, and canon-candidate yes or no.
3. Built, changed, created, deleted.
4. Everything touched. Full paths and IDs, no shorthand.
5. Open items. Each with its owner, exact next action and return condition.
6. Partial work. Where it stopped.
7. End state, as pointers.

## Rules

- Point, don't paste. Link boards, files, commits and owning documents.
- If unsure of a value, say so. Never guess.
- No secrets, credentials or PII. Token names may appear, values never.
