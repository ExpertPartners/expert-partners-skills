# Standing opening prompt (session open)

Use this to start or resume work. Keep it as a context loader. It is not a gate.

```
CONTINUITY PROMPT

We are continuing this project. Fetch the most recent continuity note for this work from the owning brain in Drive, and read Organization Instructions, the HQ Rulebook and the Decision Log. Check the actual repository, worktree, branch, open pull requests and checks. Treat the note as a predecessor's interpretation and reconcile it with what is really there. Then do the next step.

Lane: [name the lane or project]
```

The Drive fetch is deterministic. Project knowledge retrieval is not guaranteed recall, so don't swap it in.
