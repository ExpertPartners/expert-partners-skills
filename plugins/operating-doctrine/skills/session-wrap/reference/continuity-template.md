# Continuity note template

Its own document, so the next session can load it first and stand alone.

1. First line: "This note supersedes all prior continuity notes for lane [LANE]. Dated [YYYY-MM-DD]."
2. What we were doing and why, in one or two sentences.
3. Decisions still standing.
4. The exact first next step.
5. Warnings and dependencies.
6. Relevant paths, IDs and values, in full.

Prefer pointers to the owning plan, job, documents and commits over restated state. If unsure of a value, say so. No secrets, credentials or PII.
