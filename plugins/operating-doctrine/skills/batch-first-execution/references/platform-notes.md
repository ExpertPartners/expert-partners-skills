# Platform notes

- Codex and Claude Code can queue the next ordered item while a run is active. Steer changes the active run. Pick the one that fits and do it yourself.
- Check the app or CLI behavior live before naming a shortcut or setting. Do not assume a setting on Allison's machine.
- A worker that cannot start its own work, such as a plain Codex session, gets work through Factory, started by the AI.
- Browser work runs on Ember's M2 through the playwright-ember tool.
