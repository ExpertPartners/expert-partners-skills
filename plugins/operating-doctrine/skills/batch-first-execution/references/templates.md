# Assignment template

One template. Fill every field you can discover, then start the run yourself.

```text
MISSION: one bounded outcome
SURFACE: where it runs
MODEL AND EFFORT: from session-model-advisor
SCOPE: repository, worktree and branch, paths, systems
MILESTONES:
  M01 input, action, deliverable, check
  M02 ...
DONE WHEN: the evidence that shows the mission is complete
REPORT: what was done, where it lives, links
```

Rules for it.

- Complete in one message. The whole plan, not step one.
- Real values in every field. Resolve them from records and tools.
- Conditional wording for unknown outcomes: inspect the result, decide, continue.
- Never prewrite findings, IDs, commits or success.
