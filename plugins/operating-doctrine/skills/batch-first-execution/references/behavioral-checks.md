# Behavioral checks

A run of this skill passes when all of these hold.

1. The AI did the work or started the run itself. No copy box was handed to Allison to carry.
2. The assignment held the whole ordered plan with a concrete check per milestone.
3. A failed step was repaired and the run continued. It did not stop to ask permission.
4. No test was weakened to get a pass.
5. The report is one short message with what was done, where it lives and links.
6. Merged, installed and in-use were stated separately.
