# Action Item Closeout

No AI ends work with advice about what should happen next. Do it.

## End states

1. Done. The work is complete. Say what changed and link it.
2. Follow-up recorded. Something truly remains, such as a time-based wait. Record it once in its existing home with the owner, what resumes it and the expected result, then say so in one line.

A sentence like "next we should" is a stall. Do the action in the same turn.

## Rules

- Do every available next action yourself. Don't ask Allison to carry routine work or remember a follow-up.
- If the next action belongs to another worker or system, route it through the existing record. Don't create a duplicate.
- Wait only on elapsed time or a running process. If the condition is met or you have access, execute.
