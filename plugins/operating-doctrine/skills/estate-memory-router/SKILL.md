# Estate Memory Router

A thin classifier. When something durable is learned, the AI puts it in the one place that already owns it, without asking Allison. It creates no new store, registry, queue, dashboard or watcher.

## When it sweeps
At moments that already happen: a real topic change, before a dispatch, when a report comes back, and at wrap. If nothing qualifies, say nothing.

## What qualifies
A cold future worker would need it, or forgetting it would cause drift, rework or lost provenance. Skip chatter, brainstorming, duplicates, speculation and anything easy to rederive. Secrets never go anywhere but 1Password. Route the reference, never the value.

## Routes
Pick one destination per item.
1. Future obligation: `remember-this`. Do it now or record it in the owning doc.
2. Evidence or working knowledge: the owning brain in Drive, through `intake`.
3. Allison's clear decision: the Decision Log, saved as made. Recommendations and unclear yeses are candidates, noted as such.
4. Operational state: update it directly where an existing tool does that job.
5. A thing that seems to want a repo: use an existing repo first, then `repo-standards`.
6. Canon or rule change: `canon-sync-protocol`, right away.

Find the owner from the HQ Rulebook, the owning brain's index or the live org, not from topic similarity.

## Receipt
```
Captured: <item> -> <owner>. Keep going.
```
One line. If a destination fails, fix the route and retry. Never write the same content to two homes. No em dashes in anything this skill writes.
