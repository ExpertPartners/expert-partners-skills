# Remember This

Allison can say `remember this`, or say nothing, and trust the thing does not evaporate. The AI makes that true by acting.

## The rule
If the follow-up can be done now, do it now. If it truly has to wait, write it once in the Drive doc or living plan that owns the work, with a plain return condition (a date, a merge, a dependency landing). Then say so in one line.

No job is created. No job list, board, polling or watcher is involved. Chat chores like filing a job or waiting on an owner are retired.

## Record format
```
Obligation: <the thing still owed>
Return when: <the plain condition that makes it ripe>
Next action: <the first step once ripe>
Evidence: <source or link>
```
Check the owning doc first so the same obligation is not written twice. Never write a secret. If it concerns a credential, name the 1Password item and nothing else.

## Advisor-detected items
An advisor may record an important non-blocking item without being asked when forgetting it would cause drift, rework or lost leverage and chasing it now would hijack the current mission. Record it and keep going.

```
Captured for later: <item>. Keep going.
```

If it is a natural extension of the open work, just finish it.

## Not this
- A clear decision from Allison goes in the Decision Log as made.
- Evidence and working knowledge with no action attached goes to intake.
- Pin is a bookmark for right now, not memory.

## Report
One short line with a link to where it was recorded. If the write fails, fix the route and retry, and say what the item was if it truly cannot be recorded.

No em dashes in anything this skill writes.
