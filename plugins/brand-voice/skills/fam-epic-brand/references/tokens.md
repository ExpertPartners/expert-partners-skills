# FAM and EPIC Visual Tokens

Reference these whenever generating HTML, slides, web pages, marketing collateral, or any visual deliverable for the EPIC or FAM brand.

**As of Visual Identity System v3.1 (2026-06-13), FAM and EPIC are SEPARATE visual systems.** They still share voice, spelling, structure, and positioning (see the main SKILL.md and voice.md), but their colors and fonts diverge. Pick the right system before generating any asset.

## Which system to use

- Output for **Expert Partners or EPIC** (the company and its inner-circle program, Inner Circle Resources, Funnel Pilot, G2M, company-level coaching/training/events): use the **EPIC system** below (Brand Blue accent, Overpass/Poppins). Unchanged.
- Output for the **Free Agent Movement** (FAM, Free Agent Nation, Free Agent Formula, FAMOS, the movement's community/content/membership/events): use the **FAM v3.1 system** below (NO color accent, Neue Swiss, Warm Bone).
- When a single asset must carry both brands, the surrounding brand context wins: an EPIC deck that mentions FAM stays EPIC; a FAM page that mentions EPIC stays FAM.

# EXPERT PARTNERS / EPIC visual tokens (unchanged)

## Color palette

### Primary
- Black: #000000 (dominant, used for backgrounds, primary text, hero sections)
- White: #FFFFFF (negative space, secondary backgrounds)

### Accent
- Brand Blue: #2757CF (used for CTAs, links, highlights, key data points)

### Rule
Black dominates. Brand Blue accents only. No additional colors unless explicitly approved for a specific campaign. No gradients unless intentional and brand-aligned.

## Typography

- Headlines: PT Serif, Bold. H1, H2, hero text, section titles.
- Subheads: Overpass, SemiBold or Medium. H3, H4, deck subtitles.
- Body: Poppins, Light or Medium (never Bold for body). Paragraphs, captions, lists.
- Hierarchy: mix serif (PT Serif) headlines with sans-serif (Overpass and Poppins) body. Do not mix multiple serifs or multiple sans-serifs in body copy.

## Component patterns

### Buttons
- Primary CTA: Brand Blue background (#2757CF), white text, no border, slight rounded corners.
- Secondary: transparent background, Brand Blue border and text.
- Ghost: black or white text on contrasting background, no border.

### Cards
- White background on black contexts, black background on white contexts.
- Minimal shadows. Brand Blue accents for status indicators or callouts.

### Tables and data displays
- Black headers with white text. Brand Blue for emphasis rows or values. Plenty of padding.

## EPIC fonts allowed
PT Serif, Overpass, Poppins. Nothing else.

# FREE AGENT MOVEMENT (FAM) visual tokens — Visual Identity System v3.1

> v3.1 retired FAM's old system in full. The prior "FAM inherits Expert Partners" setup (Brand Blue #2757CF accent, Overpass and Poppins) is **retired for FAM**. FAM is now its own accent-less system so it can layer over each member's personal brand. Never reintroduce blue, brown, or sepia to FAM. Source of truth: ExpertPartners/fam brand/brand-guide.md + brand/identity.md.

## Color palette

### Primary
- Black: #000000 (primary dark: text, dark sections, emphasis)
- White: #FFFFFF (primary background; also used where crisp contrast is needed)
- Warm Bone: #F7F4EF (subtle warmth on cards, boxes, and select sections; never a stark all-white or all-cream surface)

### Neutrals (borders, structure, secondary text only)
- Light Gray: #F5F5F5
- Mid Gray: #CCCCCC
- Dark Gray: #333333

### Rule
NO color accent. All links, active states, buttons, and emphasis use Black or Dark Gray. Emphasis comes from contrast and typography, never a colored highlight. The Accent token maps to Black. There is no destructive/red token. Warmth comes only from photography, never the UI.

## Typography

- Headlines: PT Serif, Regular (400), line height 1.1.
- Subheads: Neue Swiss Medium (500), line height 1.35.
- Body: Neue Swiss Light/Regular (300/400), line height 1.6.
- Labels and CTAs: Neue Swiss Medium, ALL CAPS, slight negative letter spacing.
- Detail (optional): IBM Plex Mono for numbers, tags, and technical labels only.
- Neue Swiss is a licensed font owned by Expert Partners; never substitute it. (Committed font files are Neue Haas Display.)

## Component patterns

### Buttons
- Primary CTA: Black background, white text, Dark Gray (#333333) on hover, 4px radius.
- Secondary: transparent, 1px Black border, fills Black with white text on hover, 4px radius.

### Cards
- 8px radius. White or Warm Bone background. Subtle Light Gray or Mid Gray border, clean neutral shadow.
- Card-with-logo headers use a Black bar with the white logo.

### Icons
- White icons on Black or dark sections; Black icons on White or Warm Bone surfaces. Lucide, stroke width 1.5.

### Tables and data displays
- Black headers with white text. Use Black, Dark Gray, or weight for emphasis, never a color. Plenty of padding.

## FAM fonts allowed
PT Serif (headlines), Neue Swiss (subheads/body/labels), IBM Plex Mono (technical detail only). Nothing else.

# Shared across both systems

## Layout principles

- Generous white space. Avoid cramped layouts.
- Left-aligned by default. Center-aligned only for hero moments.
- Strong vertical rhythm. Consistent spacing between sections.
- Flat design by default; clean, subtle, neutral shadows only (no warm/brown tint, no blue glow).
- No clipart or stock illustration templates. Use real, rich, editorial photography or custom illustration only.

## Brand voice in visual copy

When writing copy that will appear inside a visual asset (slide, web page, social post):

- Apply all FAM/EPIC voice rules from the main SKILL.md.
- Headlines: short, punchy, declarative. No more than 7 words ideally.
- Subheads: build context for the headline.
- Body: speak to the reader directly. Avoid passive voice.
- CTAs: action verbs ("Build it," "Get clear," "Own your move," "Activate the system").

## Hashtags and social

- #eXpProud
- #BreakTheCycle
- Include both on Free Agent Movement-aligned social posts.

## What NOT to use

- Em dashes anywhere on visual assets.
- Stock photos that feel generic or "salesy."
- Colors or fonts outside the system you are working in (EPIC vs FAM above).
- On FAM specifically: never any color accent, never blue/brown/sepia/warm-neutral UI tones, never substitute the licensed fonts, never a colored FAM mark.
- Heavy gradients, drop shadows, or skeuomorphic effects.
- All-caps for body emphasis (use weight or, for EPIC only, accent color; FAM uses weight and contrast only).
