# Brand Guardian

This is our audit and revision workflow for the recovered Week 2 marketing use case. Brand Guardian is not claimed as a recovered original Cal skill package. Use the existing brand router and approved profiles rather than installing another voice bank.

## Establish the review

Resolve company, speaker, audience register, channel, draft and requested action. A request to review is not a request to rewrite or publish. Preserve the original draft and its facts for comparison.

Use `brand-voice` to read current HQ authority, Shared Writing Rules, the selected Company Core canon and applicable approved voice guide and summary. Open the actual source text, not just a search result. Follow current explicit supersession. If sources conflict without a ruling, identify the exact conflict rather than selecting a convenient version.

Keep company voice separate from founder personal voice. Do not mix EP and AG evidence, blend Allison and Don, or treat a program as the parent company. Resolve the current brand relationship and audience register from canon rather than frozen skill rules.

For each conflicting instruction, compare authority, effective date, audience scope and explicit supersession. A live document can still contain stale prices, retired brands, old punctuation or a generic profile prompt that contradicts a newer decision. Apply the newer applicable ruling and the more specific register, and record the excluded stale clause in the internal source report. Do not copy a profile's reusable prompt unfiltered or edit the external canon as a side effect.

If required authority, canon or draft is unavailable, name the failed read and stop only that dependent judgment. An available draft may still get a clearly labeled generic editorial review, not a brand pass.

## Check the draft

Always read [Anti AI Writing Guide](references/anti-ai-writing-guide.md) for the default editorial pass, including requests using that name. It is bundled reference knowledge, not a separate installable skill or a recovered original attachment.

Review in this order.

1. Factual and audience fit against current sources. Flag unsupported prices, outcomes, proof, dates, attribution and calls to action. Do not replace vague claims with invented specifics.
2. Privacy and identity boundaries. Exclude private targets, client facts and irrelevant company context from public copy.
3. Voice against the selected person's authentic patterns and accepted calibration. Preserve approved openings, rhythm and closing principles without copying example wording or deadlines.
4. Current shared writing rules and canon-specific constraints.
5. Generic Anti AI editorial observations, subordinate to all the above.

Use actual excerpt, source title and revision, reason, suggested change and disposition for each material finding. A rule sourced only from the generic reference is an editorial suggestion, not company policy. If canon intentionally uses a word the reference discourages, preserve the canon and explain precedence. Do not enforce arbitrary quotas, mandatory three-item lists or automatic percentage cuts.

## Return useful work

For an audit, return the findings and a bounded verdict with unresolved facts. Do not rewrite the whole draft unless asked. For a requested revision, return clean copy separately from an internal edit log, preserving meaning and verified facts. Explain edits in terms of audience and context, not rigid new rules.

For material longer than 200 words, the recovered three-weaknesses and one-tweak review belongs in that internal log, never pasted onto customer-facing copy. Do not invent defects to fill a quota.

Compare before and after against the same sources and requested next step. Check for phrase leakage, fabricated attribution and changed business claims. Do not assign a passing brand verdict when material facts remain unresolved. State what passed, what was not assessed and what remains missing. A model's score is not independent acceptance.

When saving is requested, use the existing owning company output home, preserve approved masters, follow current document formatting and return exact-document-name links. Report generated, persisted, installed and actively used states separately. Publication or client sending is a separate task and never part of an editorial check by implication.
