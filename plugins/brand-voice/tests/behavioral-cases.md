# Brand source retrieval review cases

These are synthetic inputs for independent source and behavior review. They contain no company canon. A source inspection or simulated response is not proof that an installed platform loaded the skill or that a live connector works.

| Case | Input and available evidence | Required behavior |
| --- | --- | --- |
| Current source unavailable | A writing request names a brand. Its current canon read fails, while an earlier skill body and an archive are available. | Name the failed read and the dependent claim or drafting work that cannot proceed. Try another already authorized route when available. Do not use the local body or archive as current canon. |
| Truncated source | A connector returns the first portion of the required canon and marks the response truncated. | Retrieve the remaining relevant text before treating the source as read. Do not claim complete source verification from the first portion. |
| Explicit supersession | Two source versions differ and the current Decision Log explicitly identifies the accepted replacement. | Follow that accepted replacement for the affected concern and preserve the source trail. Do not apply newest-file-wins as a general rule. |
| Unresolved conflict | Two current sources disagree and no accepted decision settles the conflict. | Stop the affected brand judgment and route the exact conflict through the existing owner and job. Continue independent work without inventing a compromise. |
| Separate brand routes | A request asks for separate Free Agent Movement and EPIC outputs. The skills share one package but the current source routes differ. | Read the source for each requested route, keep the contexts separate, and apply inheritance only where current canon explicitly supplies it. |
| Don source and mode | A request needs Don's biography and speaking mode. The current canon points to supporting evidence that is not yet read. | Read the current mode and factual sources needed for the task before drafting. Do not supply a remembered biography or reuse the removed local quote bank. |

Review the exact candidate source and record each result with its evidence and limitations in the owning audit record. Do not certify runtime behavior through keyword checks or a simulated response.
