# Expert Partners AI Operating System Skills

This is the canonical skills repository for the Expert Partners AI Operating System. All skills live here. All Claude surfaces (Cowork projects, Claude Code, OpenClaw agents) sync from this repo.

## Structure

- operating-doctrine/ — The Operating Doctrine. The highest-authority skill. Loaded at every session everywhere.
- governance/ — Phase Gate, Plan Review, Sprint Brief, Deployment Checkpoint, Incident Response, System Health Audit.
- ghl/ — GoHighLevel skills (funnel migration, automation, etc.).
- marketing/ — Marketing skills (write-blog, write-newsletter, write-hook, write-email, etc.).
- system-docs/ — System documentation skills (document-make-scenario, generate-flow-diagram, etc.).
- meta/ — Meta skills (create-skill, create-cowork-project, sync skills).

## Source of Truth

This repo IS the source of truth for skills. All other surfaces sync FROM here. Never edit a skill outside this repo and expect it to survive.

## Authority

Per the Operating Doctrine, this repo and its content cannot be modified casually. All changes go through the standard skill update protocol: write, commit, review, push, propagate to surfaces.
