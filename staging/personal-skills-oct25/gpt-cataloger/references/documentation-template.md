# Custom GPT Documentation Template

This is the page body every GPT entry uses. Create it once as the database page
template named "Custom GPT Documentation Template" so every new entry opens with
this structure. When cataloging a GPT, fill each section from the pasted
configuration or profile. Use plain-text section headers (no bold, no dividers).

Sections 1, 2, and 19 mirror data that also lives in the properties. That is on
purpose: the properties are the quick filter, the body is the readable record.
Keep them consistent.
