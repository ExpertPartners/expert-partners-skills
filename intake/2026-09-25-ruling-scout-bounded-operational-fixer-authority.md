# Scout bounded operational Fixer authority

## Decision

Scout is operationally authorized to perform pre-delegated low-risk, reversible repository-stewardship repairs without a new Allison approval for each exact repair plan. Auditor mode remains read-only. Fixer mode may make bounded repairs only when accepted authority already dictates the desired state and the live per-job evidence, scope, collision, rollback, test, isolation, and GitHub-authorization checks pass.

Delegated repair classes include repository front doors and indexes, AGENTS.md / CLAUDE.md structural corrections, stale pointers to already accepted destinations, broken local navigation, historical or superseded labeling, metadata/frontmatter corrections supported by existing facts, generated-artifact labeling/protection, baseline CODEOWNERS / .gitattributes where the standard dictates the result, and similarly bounded organization or curation that preserves history and established ownership.

Scout is not authorized by this decision to self-merge, bypass branch protection or review, force-push or rewrite history, delete unique source history, change repository topology or canonical ownership, change credentials/access/rulesets/security, spend money, accept legal terms, deploy production, change DNS or material runtime infrastructure, create new business truth, or resolve a genuine conflict between current authoritative sources without an accepted supersession.

Formal Grok Gates A-D remain qualification evidence and are not marked passed by this decision. They no longer act as an absolute operational veto over the specifically delegated repair classes above.

## Date

2026-09-25

## Replaces

Supersedes the repo-standards v1.5 / Grok Repo Fixer v1.0 absolute operational Gate D block and the requirement for Allison to approve each exact repair plan for the delegated low-risk reversible classes. It does not supersede normal repository protections, independent review requirements, merge authority, or the excluded-action boundaries above.

Allison explicitly directed that Scout become Fixer-capable so routine repository stewardship no longer routes back through her for every repair, then issued the exact command `Lock that` on 2026-09-25. Repo Standards v1.6 and Grok Repo Fixer v1.1 already implement the intended bounded operating model; this record makes that delegation durable under the Foundation Memory Protocol.
