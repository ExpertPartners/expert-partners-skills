# Sourcing waterfall

Search in this order and stop at the first tier that clears identity, rights and technical fit. Record every source searched in the evaluation's `search_log`, including zero-result searches; they are evidence that the route to permission or commission was earned.

1. Owned and cleared library. The visual-assets register first, then approved owned libraries named by the brand (its commissioned photography).
2. Openly licensed and VERIFIED. Wikimedia Commons (CC0, public domain and BY before BY-SA), then Flickr Creative Commons (BY, BY-SA, CC0, PDM only; never NC or ND), with Openverse as a discovery aggregator whose license data is confirmed on the original page.
3. Owner permission. Developer or community marketing team, HOA (confirm who shot it), builder, city or tourism bureau, or the photographer who owns the best existing image. For named communities this is usually the fastest route to a correctly identified, high-quality image.
4. Paid license. For city-scale scenes a stock image can positively identify (skyline, a named district), from the approved stock services.
5. Commission. A local architectural or drone photographer under a written perpetual license or work-for-hire grant. The default route for top named communities. Drone work falls under FAA Part 107.
6. Generic mood stock. Only for non-identity use: blog headers, lifestyle, textures, social filler. Never on a page that names a place.
7. AI-generated imagery never depicts a real named place.

## Tool neutrality

The method does not depend on any one vendor. Use the best approved research, search or browser path available on the current surface. Perplexity is preferred for deep web research when present; the Wikimedia Commons MediaWiki API and the Openverse API serve free candidates directly; other approved tools run the same steps. Whichever tool runs, the evidence lands in the same structures and the same scripts decide.

## Boundaries while sourcing

- No scrapers built to defeat rate limits, bot walls, paywalls or terms. When a vendor restricts automated access, use its API or a human session, or record the source as not searched.
- Capture the source page and license page to Drive on the acquisition date for any candidate that reaches a card with LICENSE, REQUEST PERMISSION or USE.
- Stock sites usually strip EXIF. Absence of EXIF proves nothing either way.
- Candidates that fail identity or rights early can be screened with one line of reason; spend review effort on the candidates that could actually clear.
